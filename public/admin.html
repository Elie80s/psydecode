Mise en Ligne & Déploiement Cloud (Production)

Votre site est 100% autonome et sans dépendance lourde :
Il fonctionne avec du pur HTML/CSS/JS et une API Node.js ultra-légère. Vous pouvez le déployer gratuitement en quelques minutes sur n'importe quelle plateforme moderne.

Option 1 : Render / Railway (Recommandé pour Node.js)

Déploiement complet en 1 clic avec le serveur Node.js, l'API et le système d'upload.

  1. Créez un compte gratuit sur render.com ou railway.app.
  2. Poussez le dossier sur votre compte GitHub.
  3. Cliquez sur New Web Service ➔ connectez votre dépôt.
  4. Commande de démarrage : node server.js

Option 2 : VPS / Hébergement Dédié (OVH / Hostinger)

Idéal pour relier directement votre propre nom de domaine psydecode.com avec certificat SSL Let's Encrypt gratuit.

  1. Installez Node.js sur le serveur.
  2. Copiez le dossier psydecode-site.
  3. Lancez avec PM2 : pm2 start server.js --name "psydecode"
  4. Configurez Nginx comme reverse-proxy sur le port 3000.
